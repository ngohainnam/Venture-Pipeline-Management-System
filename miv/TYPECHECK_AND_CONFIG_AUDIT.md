## Risks and Dependencies Between Fixes

- Prisma generated types are central. Running `prisma generate` after schema/package changes may change many diagnostics; do that before deeper API fixes in any approved remediation stage.
- Schema changes are high blast radius because seed scripts, dashboard APIs, and UI DTOs all depend on the current generated client.
- The missing mobile component imports block the Next build before later build-time type/runtime issues can be fully observed.
- Font fetch failures are environment-dependent; fixing them improves CI/offline repeatability but may affect typography.
- React hook warning fixes can change fetch timing and render loops; defer until API/type contracts are stable.
- Excluding archived scripts/pages can produce a clean app build faster, but may hide intentionally supported maintenance tooling.
